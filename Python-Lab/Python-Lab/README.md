## 📁 Structure

| Unit | Topic | Programs |
|------|-------|----------|
| Unit-1 | Basics, input/output, operators, functions | Student report, calculator, math operations, electricity bill |
| Unit-2 | Loops and recursion | Prime check, factorial, Fibonacci (loop and recursion), OTP generator |
| Unit-3 | Dictionaries and control flow | Frequency counter, grading system, contact book, attendance tracker |
| Unit-4 | File handling | Log reader, student records (TXT), payroll (CSV), log analysis (JSON) |
| Unit-5 | OOP and data visualisation | Bank account, library system, dice roll, sales dashboard |

## ▶️ How to run

```bash
python Unit-1/program1.py
```

Unit-4 programs read and write files in the folder you run them from, so run `program1.py` from inside `Unit-4/` (it reads `log.txt`).
Unit-5 `program4.py` needs matplotlib: `pip install matplotlib`.
